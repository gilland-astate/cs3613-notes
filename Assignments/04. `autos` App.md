# Objective
In this assignment, you will build a fully functional **CRUD (Create, Read, Update, Delete) application** to manage automobiles and their makes (e.g., **Ford, Hyundai, Toyota, Tata, Audi, etc.**). This will give you hands-on experience in Django’s **model-view-template** architecture, authentication system, and generic class-based views.

Your application will allow users to:  
✅ **View a list of automobiles and makes**  
✅ **Create new automobile and make entries**  
✅ **Edit and update automobile details**  
✅ **Delete automobiles from the database**

Additionally, you will:
- Implement **user authentication** for managing entries.
- Utilize **Django's built-in admin panel** to manage data.
- Follow best practices by using Django’s **generic class-based views** where possible.

By the end of this assignment, your Django project will have:
- A **new application (`autos`)** integrated into an existing Django project.
- Proper **URL routing and navigation** between views.
- A **Tailwind-styled** user interface.

# Things that can go wrong
If you ever get a 405 error on a Django page it probably means that you have defined a view class that does not have a `get()` method. For example if you meant to say this:
```
class AutoUpdate(LoginRequiredMixin, UpdateView):
    model = Auto
    fields = '__all__'
    success_url = reverse_lazy('autos:all')
```
But instead you did:
```
class AutoUpdate(LoginRequiredMixin, View):
    model = Auto
    fields = '__all__'
    success_url = reverse_lazy('autos:all')
```
(i.e. you extended `View` instead of `UpdateView`) - the result is that there is no `def get(self, request):` in your view. So you get the [405 HTTP status code](https://en.wikipedia.org/wiki/List_of_HTTP_status_codes#4xx_Client_errors) (invalid method) when you navigate to the URL that forwards to the view.
